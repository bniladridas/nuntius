nuntius

Ruby client for Gemini

A compact, dependency-light client for Google Gemini text generation, with a CLI and a PR review app.

View on GitHub Nuntius App

Install

gem install nuntius-rb --pre

Add it to your Gemfile with gem 'nuntius-rb', require: 'nuntius'.

Use

require 'nuntius'
Nuntius.load_env

client = Nuntius::Client.new
puts client.generate_text('Write a haiku about Ruby')

Set GEMINI_API_KEY in your environment or .env file.

CLI

./bin/nuntius generate "Your prompt"
./bin/nuntius chat
./bin/nuntius test
